# character.json

一个角色的全部专属信息。坐标都是画布像素，左上角为原点，y 向下。`rigkit.estimate` 会按图层量出初稿，下表里标「量」的字段由它填，标「默认」的沿用第一个角色调好的值并按脸的大小缩放。

## 顶层

| 字段 | 含义 |
|---|---|
| `name` | 显示名 |
| `model_id` | 模型文件名（不含扩展名） |
| `canvas` | 画布宽高 |
| `art` | 素材文件夹（含 `layout.json`、`parts/`），相对本文件 |
| `prepared` | 网格和贴图文件夹，默认 `prepared` |
| `reference` | 原画，素材检查对照用：`{"image": 路径, "shift_y": 下移像素}` |
| `layers` | 名字不在 [图层清单](图层清单.md) 里的图层怎么动，见下 |

## layers

只写需要说明的图层。每项可有：

| 字段 | 取值 |
|---|---|
| `role` | `face`（随脸转）、`hair`、`neck`、`body`、`pose`、`cheek`、`dangle`（挂件），以及眼、眉、嘴的各角色 |
| `group` | `head` / `neck` / `body` / `pose` |
| `lock` | 头发：跟哪一缕一起摆（同一缕拆成几层时都指向它） |
| `neck_hold` | 头发：`hold`（贴着脖子的发丝跟脖子不动，默认）、`behind_jaw`（下巴后面的发丝也跟脖子）、`none` |
| `warp` | 变形器分组，一般不用写 |

## head

| 字段 | 含义 | |
|---|---|---|
| `pivot` | 歪头的转轴，在脖子里、下巴下方 | 量 |
| `tilt_deg` | ParamAngleZ 满幅时头歪的度数 | 默认 10 |
| `face` | 脸的椭圆：`centre`（眼睛高度）、`rx`、`ry_up`（到额头）、`ry_down`（到下巴） | 量 |
| `silhouette` | 头发外轮廓离脸多远（脸椭圆的倍数），之外的头发轻微反向移动 | 默认 2 |
| `yaw_px` | 左右转满幅时脸中线移动的像素 | 默认 |
| `pitch_px` | 抬头、低头满幅时的像素 `[抬, 低]` | 默认 |
| `rigid` | 五官保留曲面形变的比例，越小越像整块平移 | 默认 0.6 |
| `features` | 眼、眉、鼻、嘴的中心 | 量 |
| `bun` | 发髻当成球：`centre`、`radius`、转动量、和头顶衔接的范围 | 量 |
| `nose_turn` | 鼻子侧线的显隐（有 `Nose_Turn_*` 图层时） | 默认 |

## neck

| 字段 | 含义 |
|---|---|
| `chin_v` | 下巴底边三点（左、中、右）；脖子在它下面的部分固定 |
| `tilt_band` | 脖子跟着歪头的范围 `[到这一行为止, 过渡像素]` |
| `hair_hold` | 离脖子多近的发丝跟脖子不动 |
| `behind_jaw_from` | `behind_jaw` 的发丝从哪一行开始跟脖子 |

## eyes / brows / mouth

| 字段 | 含义 |
|---|---|
| `eyes.half_width` | 眼睛半宽，闭眼曲线按它归一 |
| `eyes.iris_travel` | 看左右、上下时虹膜移动的像素 |
| `eyes.closed_art` | 闭眼线取自哪里：默认 `Eye_Closed_*` 图层；`ink_below` 是线的亮度上限 |
| `eyes.crease_fade` | 双眼皮在睁眼程度从第一个数降到第二个数之间淡出，默认 `[0, 0.08]`（闭上才消失）；第二个角色用 `[0.4, 0.85]` |
| `eyes.lower_from` | 下眼睑在睁眼程度低于这个数后才开始往上合，默认 `1`（一闭眼就合）；第二个角色用 `0.45` |
| `eyes.closed_swap` | 睁眼程度从第二个数降到第一个数之间，换成闭眼图层 `Eye_Closed_*` 画好的闭眼，同时隐藏眼白和眼珠；`estimate` 写 `[0.12, 0.15]`，没有这一项时不换 |
| `brows.tail_x`、`brows.length` | 眉尾位置和眉长，眉形变化从眉尾往眉头走 |
| `mouth.variants` | ParamMouthVariant 各值对应的嘴型 |
| `mouth.open_band` | 张嘴时上下拉伸的行范围 |
| `mouth.form` | 嘴角上扬、下垂：`centre`、`half`（半个嘴宽，变形衰减到嘴角）、`lift`、`drop`（像素） |
| `mouth.open_from` | 摄像头的张嘴读数低于它时保持闭嘴，之上再逐渐张开；新角色默认 0.1，不写时为 0 |

## hair

| 字段 | 含义 |
|---|---|
| `locks.<图层>` | 每一缕会摆的头发：`param`、`swing`（满幅像素）、`pitch`（点头时的拖尾像素）、`root`（发根 `[行, 长度]`，长度为负表示发根在下方，如发髻）、`tip`（发梢参数名，可选）、`physics`（VTS 物理）、`body_from`（长发：`[行, 过渡像素]`，从这一行往下交给身体） |
| `anchor_layer` | 头发在这一层附近不动（可选） |
| `bend` | 摆动时的弯曲：中心列、宽度、弯曲量 |
| `tips` | 发梢从哪一行开始弯、多长、满幅像素 |
| `lattice` | 头部动作取样的格子：间距、范围、额外点。范围要包住所有随头动的层（帽子在内），格子外的部分会被切掉 |

## body

| 字段 | 含义 |
|---|---|
| `centre_x`、`neck_y`、`shoulder_y`、`waist_y`、`radius` | 身体中线、颈根、肩、腰、躯干半宽 |
| `turn`、`shift`、`side` | 身体左右转：胸口中线像素、整体平移像素、两侧占比 |
| `lean_y`、`lean_scale` | 前后倾：肩膀上下像素、上身宽度变化 |
| `pivot`、`tilt_deg` | 身体倾斜的转轴和每单位参数的度数 |
| `breath` | 呼吸：脖子以上、肩膀的起伏像素，胸口变宽比例 |
| `grid` | 身体网的网格线 `xs`、`ys`，等间距（不等间距会在关键形之间翻折） |

## dangles

| 字段 | 含义 |
|---|---|
| `dangles.<图层>` | 每个挂件：`param`（摆动参数）、`pivot`（挂点，上端中间）、`deg`（满幅度数）、`follows`（`body` 或 `head`） |

## poses / cheek / vts

| 字段 | 含义 |
|---|---|
| `poses.layers` | `[图层, 开关参数]`；`priority` 同时打开时谁优先 |
| `cheek.param` | 脸红参数（有 `Cheek_Flush_*` 图层时） |
| `vts.name`、`vts.file_name`、`vts.folder` | VTS 里的显示名、文件名、文件夹名 |
| `vts.expressions`、`vts.gestures` | 表情快捷键和手势，不写时用默认的一套 |
| `vts.icon_crop` | 图标取画布的哪一块 |
