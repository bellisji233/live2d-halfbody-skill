# 图层清单

出图或拆图前按这份清单准备素材。图层名就是绑定规则：名字对了，转头、眨眼、头发摆动会自动接上；名字不在清单里的头部图层，只跟着脸转。

## 通用要求

- 每个图层是一张和画布同尺寸的 RGBA PNG，彼此对齐，放在 `parts/`。
- `layout.json` 按从下到上的顺序列出图层：`name`、`texture`、`group`（`head` / `neck` / `body` / `pose`）、`visible`。
- `_L` 指画面左侧，`_R` 指画面右侧。
- 正面能看到的像素必须是原画。补画只用在原来被挡住、动起来会露出的地方。
- 每个图层只放这个部件自己的像素。不拿合成后的截图当贴图。
- 原画上的每条线都要落在某一层上。下巴线属于脸，不属于脖子。

## 头部（group: head）

| 图层 | 内容 | 被挡住、要补画的部分 |
|---|---|---|
| `Hair_Back` | 头后面的全部头发；长发连同垂在背后的部分 | 一直画到脸、耳朵、脖子后面：转头时脸边露出的是头发，不是背景。长发画到身体后面 |
| `Hair_Tail_L/R`（可选） | 双马尾，从发绳往下 | 在 `Hair_Back` 上面；`Hair_Back` 沿交界往马尾里多画一点 |
| `Ear_L` `Ear_R` | 整只耳朵 | 被侧发挡住的部分 |
| `Face_Skin` | 脸皮和下巴轮廓线 | 刘海下的额头画到发际线；眼、眉、鼻、嘴下面是连续的皮肤，不留洞；刘海投在额头上的阴影画在这一层 |
| `Blush_L` `Blush_R` | 腮红（可选） | 不带脸的轮廓线 |
| `Eye_White_L` `Eye_White_R` | 眼白，形状就是眼睛开口 | 不带睫毛 |
| `Iris_L` `Iris_R` | 虹膜、瞳孔、高光 | 被上下眼睑挡住的部分画完整的圆 |
| `Eye_Open_L` `Eye_Open_R` | 上睫毛和上眼睑 | 不带眼白 |
| `Eye_Lower_L` `Eye_Lower_R` | 下睫毛（可选） | |
| `Eye_Crease_L` `Eye_Crease_R` | 双眼皮褶（可选） | |
| `Eye_Closed_L` `Eye_Closed_R` | 闭眼的那条线，画在眼睛闭上的位置 | |
| `Eye_Smile_L` `Eye_Smile_R` | 笑眼（可选） | |
| `Brow_Neutral_L` `Brow_Neutral_R` | 眉毛 | 压在眉毛上的发丝画在刘海层，眉毛层里补完整 |
| `Brow_Angry_*` `Brow_Troubled_*` | 生气、困扰的眉毛（可选） | |
| `Nose` | 鼻子 | |
| `Mouth_Closed` | 闭嘴的唇线 | 只有线，不带一块肤色底 |
| `Mouth_Open` | 张到最大的嘴，含口腔 | |
| `Mouth_O` `Mouth_Line` `Mouth_Frown` | O 型嘴、一字嘴、撇嘴（可选） | |
| `Hair_Side_L` `Hair_Side_R` | 脸两侧、耳朵前面的侧发（可选：头发别在耳后时没有） | 发根往上画到刘海下面；里面不带耳朵和下巴线 |
| `Hair_Bang` | 刘海（可选） | 不带额头阴影 |
| `Hair_Bun` | 发髻、马尾等头顶的发团（可选） | 和头顶接触的地方画到头发下面 |
| `Glasses` | 眼镜（可选），只有镜框，镜片透明；在五官上面、头发下面，跟着脸转 | 被头发挡住的镜腿画完整 |
| `Hat` | 帽子（可选），连同上面的饰物；跟着脸转 | 只画帽子本身；被帽子挡住的头顶画在头发层 |
| `Eye_Open_Over_L` `Eye_Open_Over_R` | 压在头发上的睫毛尖（可选） | 用 See-through 合成时留空：睫毛整条在头发下面，转头时不和眼睛断开 |
| `Cheek_Flush_L` `Cheek_Flush_R` | 脸红快捷键显示的深腮红（可选），`visible` 设为 `false` | 延伸到头发和下睫毛下面，边缘柔和 |

## 脖子（group: neck）

| 图层 | 内容 | 被挡住、要补画的部分 |
|---|---|---|
| `Neck` | 脖子 | 上端画到下巴后面约脸高的八分之一，不带下巴线：转头时下巴从脖子前面滑过，后面要有脖子 |

## 身体（group: body）

名字不限，例如 `Chest`、`Body_Vest`、`Sleeve_L`、`Arm_R`、`Skirt`、`Belt`、`Bow`，从下到上排好即可。身体整体跟随左右转、前后倾、呼吸和倾斜。

## 挂件（group: body 或 head）

`Dangle_1`、`Dangle_2`……：项链吊坠之类绕上端摆动的小件，每件一层，放在它挂着的那一组最上面。底下的衣服要画完整：吊坠摆开时露出来。只有一张立绘时由 V9 拆出，见 [出图](出图.md)。耳坠（`Dangle_Ear_1`、`Dangle_Ear_2`）在 head 组、脸皮上面，绕耳垂摆动，由 See-through 的耳饰层拆出。

## 手势（group: pose）

`Pose_Wave`、`Pose_Explain`、`Pose_Point`：做这个手势时脖子以下的整个身体，含两只手臂。手势打开时代替整个身体组，`visible` 设为 `false`。只有一张立绘时由 `rigkit.extras` 生成，见 [出图](出图.md)。

## 检查

素材放好后运行素材检查，`露底` 和 `原画对照` 两项干净再往下做：

```
python -m rigkit.check_art 角色/character.json
```
